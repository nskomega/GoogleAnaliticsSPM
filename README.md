# GoogleAnaliticsSPM

## О проекте

Небольшой интеграционный проект: упаковка стороннего Google Analytics SDK 3.21.0 для Swift Package Manager. SDK принадлежит его разработчику; этот репозиторий посвящён способу подключения. Пример относится к версии SDK, указанной в проекте.

Это исторический пример iOS/Android-кода. Основное текущее направление — Flutter / Dart; актуальный открытый Flutter-проект — [Objectno](https://github.com/nskomega/Objectno).
